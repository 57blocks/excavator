## 验收中发现并修复的问题

- **图的方框是黑色**（`aeda7f6d`）：地图的样式 `.node rect { fill: var(--fill) }` 作用于页面上所有 SVG。Mermaid 的图有自己带作用域的样式，压过了它；beautiful-mermaid 用属性上色，优先级更低，于是图里的矩形节点被填成黑色（那里没有 `--fill`），字号也被改掉。地图的样式现在限定在 `.atlas-map` 内。浏览器测试新增断言：画出的图里没有黑色矩形；在旧样式上这条断言失败（4 个），修复后通过。修复后在 5 个功能页的全部图上复查：640 个图形没有黑色，文字是设计的 13px 与 11px，页面样式里只有全局重置和 Mermaid 自己的 `p` 文字规则会作用到图内（本变更之前就是这样）。
- **概览标签页顶部多出一段空白**：概览以一个只给搜索跳转用的隐藏小标题开头，后面第一个可见小标题的上边距没有去掉。已修。
