## 问题清单（运行中只记录，未修）

1. **findings 一章写不出来。** 写作子代理写 `chapters/findings.md` 时被 Claude Code 自己拒绝，理由是子代理应把结果作为文字返回、不要写报告文件；同一批其他章都能写。remedies 依赖它，也没写。
2. **用量上限停下时结束状态仍是 `success`。** 只有最后的文字是限额提示；只看状态会误以为跑完了。
3. **产品视图的表格留下空列。** 写作者把引文放在单独的「引用」列，去掉引文后这一列为空，共 440 张表。
4. **少数中文句子以英文句点结尾。** 约 231 处写成英文的括号与句点，约 9169 处是中文写法；提示词里的引文示例是英文写法。
5. **功能提示词没给填入口的命令。** 提示词要求编排者从地图与候选文件填入每个功能的入口，但没给命令；编排者自拟的 `jq` 失败一次后改对。
6. **个别表格的窄列被挤成一字一行。** 页面显示问题。
