## 验收中发现并修掉的问题

- **整份运行打不开**：
  - `check` 把「领域」一章的摘要与 `domains.json` 的摘要合在一起记，读取运行时仍按章节本身的摘要比较；
  - 结果是所有带清单的运行都被拒，报「检查后被改过」；
  - 由第二部分的编码子代理在测试里发现。修复是 commit `fix(handbook): a run whose domains record carries the list digest loads again`。
- **侧栏与手机列表重复域名**：地图侧栏和手机列表里，同一个对方域下的每条交接都重复写一遍域名。改为和业务域页一样按对方域分组。
- **技术视图的概括列带引文**：首页业务域表的「做什么」列和侧栏的概括带上了整组引文，占满一屏。改用产品视图的文字，引文留在业务域页。
- **引言里的引文太大**：业务域页引言里的引文用了引言的字号。改为与正文引文相同的小号等宽灰字。
- **手机横向滚动**：技术视图下，正文里的长引文路径、数据页的条目、状态字典的规则列表把手机页面撑宽（441 到 653 像素）。改后 10 个页面在 390 像素下都没有横向滚动。
- **帮助文字过时**：`page` 命令的帮助仍写「按部分导航」，已改为业务域地图。

## 残余问题

- **拥挤**：
  - 52 条交接里，「平台与后台任务」一个域交出 13 条，未选中时它附近的线很密；
  - 同方向的多条交接画在同一条路径上，互相重叠，各自仍能点中；
  - 选中一个域之后可以读清。
- **未在真实数据上验证的部分**（这次的运行没有用到）：
  - 中心域与虚线框，只有单元测试与合成夹具覆盖；
  - 超过 16 个域时环的可读性。
- **技术视图独有的运行**：只有技术视图时，首页的概括列没有产品文字可用，仍会带引文。
- **搜索范围**：
  - 不含数据、状态字典、代码健康与覆盖四页；
  - 小节编号按产品视图的文字算，技术视图若多出小节，编号会错位，这次运行没有出现。
- **不加链接的地方**：
  - 业务域页正文表格里的「名字 (F12)」不加链接，只有交接内容里的会加；
  - 功能页交接条里提到本功能时，也链接到本页。
