## 已知局限（照记，不在这一片修）

- **建议词误报**：
  - 记下的建议词问题是误报：英文 run 是 4 条，翻译固定文字后的中文 run 是 11 条。
  - 来源有两个：一是引号里照抄的英文界面文字含 "must" 和 "should"；二是中文建议词表含「必须」，而正文用它描写产品规则（例如「必须上传」）。
  - 建议词检查没有排除引号内的文字，也分不出描写和建议。
  - 这些只是记数，不拒绝。下一片核对时一起处理。
- **测试用的环境变量**：`EXCAVATOR_HANDBOOK_ALLOW_V2_ENTRY` 只给旧测试用，让 `/2` 能通过 `check-entry`。skill 从不设置它。
- **功能所属应用与领域文件的统计**：`/3` 条目在这里只数事实表的出处，不数正文的出处。
- **流程图的节点**：请假领域这次只有 F8 进了手册，所以流程图只有状态节点。领域里其他功能写好以后，图里才会出现功能之间的交接。
- **页面问题**：第一次看真实页面时发现三处。
  - 正文每句一段，读起来像清单。提示词已经要求同一件事的句子成段，下次写作才生效；这次的请假正文仍是一句一段。
  - 正文小节标题的字重和正文一样。已改为加粗，并在浏览器截图里核对过。
  - 流程图边上的文字互相重叠，箭头也从文字中间穿过。现在按标签长度留出间距，文字画在所有箭头之上并带一圈背景色描边，浏览器截图里能看清。
