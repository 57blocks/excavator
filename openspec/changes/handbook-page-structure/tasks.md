## 1. 缺陷解析与检查（design D2）

- [x] 1.1 缺陷解析器（`skills/excavator-product-handbook/lib/` 下新文件）：按二级小节取等级，行首加粗词取类别，全角与半角括号里的 `F数字` 或 `system` 取功能编号，跨行的项以下一项或小节为界；拆不出的项带行号与缺少的部分返回。验证：单元测试覆盖三个等级、多功能项、跨行项、缺编号、缺类别、类别不在表里、`$NONE` 的空等级。
- [x] 1.2 `check` 对缺陷章调用解析器并加三条规则（每项可拆、编号在地图上或是系统、问题一节有项的功能至少出现一次）。验证：每条规则一个反例夹具让 `check` 不通过且原因写出行号或功能；一份合格夹具通过；现有 `check` 测试不回归。

## 2. 页面数据里的问题表（design D1、D3、D4、D5）

- [x] 2.1 写页面时组装问题表：缺陷（解析器）、保留的设计问题（与 `review render` 同一读法）、系统与功能章节的待确认事项；每行带类型、等级、类别或维度、功能编号、一句话、全文字段、引文、来源章节。验证：用夹具输出断言三种行数与字段，技术视图带引文、产品视图不带。
- [x] 2.2 改进措施锚点：按类别名、维度名在对策一章的二级小节标题里找，恰好一个才给锚点。验证：测试覆盖找到一个、零个、两个三种情况。
- [x] 2.3 来源状态：可用、没有写、没通过检查、检查后被改过，写进页面数据。验证：测试为每种状态各造一份夹具，断言状态值，不可用时没有对应的行。

## 3. 问题页（design D7、D8）

- [x] 3.1 路由与问题页组件：表、默认排序、按业务域／功能／类型／等级／文字筛选，筛选写进地址；表头的计数；行展开（全文、理由或现状后果、引文、改进措施链接）；「改进措施」标签页显示对策一章；来源状态的固定文字。验证：组件测试渲染到字符串，断言排序、带筛选地址打开的结果、展开内容、各状态的文字；`ui-strings.json` 新键的测试通过。
- [x] 3.2 缺陷与设计问题两章不再作为参考页，搜索索引不收它们的小标题。验证：`pages`、`search` 的测试断言两章不在参考资料与索引里，其余参考页不变。

## 4. 功能页（spec「功能页」）

- [x] 4.1 「本功能的问题」一段与改造后的「问题」标签页（三节、来自问题表；缺陷不可用时退回章节自己的问题一节并写明原因）。验证：组件测试断言计数、至多三条的选法与顺序、两个链接的地址、没有问题时的固定文字、退回时的显示。
- [x] 4.2 左栏改为全部业务域、当前域展开、每个功能带问题数。验证：组件测试断言当前域展开、其余收起，点另一个域能展开。

## 5. 总览与顶栏（design D6）

- [x] 5.1 首页改为总览：标题与计数、业务域 × 功能格子（问题数与最高等级的文字标记）、格子下的交接地图；没有 `domains.json` 时按部分分块并写明原因；窄屏为展开列表。验证：组件测试断言 0 个问题的功能显示 0、格子的数等于问题表按功能筛选的行数、旧运行的退路；地图布局的现有确定性测试不回归。
- [x] 5.2 顶栏改为总览、功能、问题、参考资料（默认收起）、搜索、视图切换；面包屑以「总览」开头。验证：`navigation`、`TopBar` 的测试断言各项与面包屑。

## 6. 验收（design 的 Oracle）

- [x] 6.1 在已有真实输出的副本上跑 `check` 与 `page`，不运行写作代理：三种行数与脚本独立数出的一致；72 个功能逐个比较三处的数；缺设计问题、缺陷章不通过两份副本的状态显示；逐功能比较问题一节的项数与涉及它的缺陷数，差距大的抽查。结果写进 `acceptance.md`。
- [x] 6.2 无头浏览器验页面：宽 1440 时首页一屏看全格子；格子到功能一次点击；功能到问题页筛选一次点击；手机宽度没有横向滚动；页面大小与改动前对比。结果写进 `acceptance.md`。

## 7. 功能页一页连续、总览先看关系图（design D6、D9、D10）

- [x] 7.1 总览改为一句话、关系图、计数、格子的顺序；没有地图时的说明放在关系图的位置。验证：组件测试断言四部分的顺序与没有地图时的退路；现有地图测试不回归。
- [x] 7.2 左栏默认全部展开，当前功能标出并在左栏里滚到可见处（不滚动整页）。验证：组件测试断言全部业务域展开、当前功能标出、读者能收起一个域。
- [x] 7.3 功能页去掉标签页，改为页眉加五个板块：页眉的计数能跳到问题板块的小节；认不出的小节自成板块放在问题之前；每项默认收起、板块可全部展开；搜索与链接定位时展开包含它的折叠；标题编号与搜索索引不变。验证：组件测试断言板块顺序、空板块不显示、认不出的小节的位置、计数链接的目标、定位时的展开；原有问题段与问题板块的测试（计数、退回章节自己的问题、来源状态）照样通过。
- [x] 7.4 右侧本页导航：由页面拆出的板块与小节画出，点一项滚到那里，滚动时标出当前位置，窄窗口不显示。验证：组件测试断言导航项与板块、小节一一对应；`activeIndex` 的现有测试不回归。
- [x] 7.5 用词：显示给读者的「交接」改称上下游，新增板块名与上下游说明的固定文字键，`chapter.section.handovers` 不改。验证：`ui-strings` 的测试通过；扫描固定文字中显示用的字串不再说 hand-over（章节小标题的键除外）。
- [x] 7.6 验收：在真实输出副本上重新生成页面，用无头浏览器验证 design 的 Oracle 里第 7 组的各项，72 个功能逐个比较页眉计数与问题页筛选行数；结果追加到 `acceptance.md`。

## 8. 导航到左栏、总览只留关系图（design D6、D11）

- [x] 8.1 顶栏只留系统名、搜索（文字「搜索」）与视图切换；左栏在每一页都有，分全局与业务域两种状态；手机上菜单里是当前状态的左栏；面包屑的其他各页改为「总览 / 页名」；去掉「功能」「参考资料」两项。验证：组件测试断言顶栏只有三样、各类页面左栏的状态与各项、业务域状态标出当前域或功能、技术视图才有系统架构；固定文字测试通过。
- [x] 8.2 总览只留系统名、一句话、关系图与打开第一个业务域的按钮；点关系图里的域打开业务域页；业务域页列出它的全部功能，带问题数与最高等级。验证：组件测试断言总览没有功能清单与计数、点域与按钮的去向、没有地图时的退路、业务域页功能的数等于问题表按功能筛选的行数；地图布局的确定性测试不回归。

- [x] 8.4 验收：在真实输出副本上重新生成页面，用无头浏览器验证 design 的 Oracle 里第 8 组的各项，72 个功能逐个比较业务域页、功能页页眉与问题页筛选三处的数；结果追加到 `acceptance.md`。
