## 决定

- **D1 侧栏**：`.rail` 只有一个滚动容器，页面链接、功能列表与图例都在里面；顶栏保持 sticky。当前页对应的导航项进入可视区（`scrollIntoView({block: 'nearest'})`）。
- **D2 表格**：表格按列的类型给宽度：文字列 `min-width`（约 16em），短值列 `white-space: nowrap`，路径用 `<code>` 并在 `/` 后插入可断点（`<wbr>`），不靠 `overflow-wrap: anywhere` 逐字断开。窄屏下表格在自己的容器里横向滚动，页面不滚动。
- **D3 源码位置**：一个组件同时给功能页、概览、发现、系统发现使用。按项分组；项的路径与主张从数据里已有的字段取（不解析拼好的字符串；数据只有拼好的字符串时，按固定分隔符拆，拆不开就整段显示）；每处引用一个 `<code>` 块，同一文件的多处合成「文件: 行, 行-行」；整节是 `<details>`，默认收起，摘要里写项数与引用数。
- **D4 不动数据**：页面数据格式 `/14`、`handbook.md` 的结构都不变。新加的界面文字（如摘要里的计数）走固定文字表的新键。
- **D5 正式用词**：改约 15 个键的英文值（键与占位符不变），翻译提示加一句语气要求。已有运行的 `ui.json` 是旧译文，要换成新用词需要删掉它、让下一次运行重新翻译（Phase 2）。改值前先查有没有脚本或面向模型的提示依赖原文。
- **D6 仍是一个文件**：用户允许输出多个文件，但单文件已经能内联编译好的 Tailwind 与打包的组件库，双击即开；拆成文件夹要改 `page` 的输出、CSP、部署夹具与模板契约，读者得不到什么。所以控件改进不改输出形态。代价：模板体积随组件库增加（预计几十 KB），超过 1 MB 的增量才重新考虑拆分。
  - 数据量：一次真实运行 54 个已核实功能时，模板约 0.66 MB，页面约 2.5 MB（数据约 1.9 MB，最大的是字典约 1 MB）。数据随功能数与字典大小增长，不随代码行数增长。单文件的硬上限是 V8 单个字符串约 5.37 亿字符，数据接近几百 MB 时写页面或打开页面会失败。
  - 大数据的形态（已实测，不在本变更实现）：`index.html` 加 `data/part-NNNN.js` 分块，每块调用一个全局函数登记自己，页面按需插入 `<script>` 加载；`file://` 下、CSP 为 `script-src 'self' 'unsafe-inline'` 时，3 块各 6000 万字符共 1.8 亿字符在无头 Chrome 里正常加载。到 GB 级还要按页按需加载、长表格虚拟滚动，不能一次全部渲染。
- **D7 组件**：只为需要弹层与键盘交互的控件引入 Radix UI 原语（下拉选择 `@radix-ui/react-select`；其他按需，不预先铺开）；样式用 Tailwind 写在 `src/components/ui/` 里的薄封装中（shadcn 的写法，代码进仓库，不用它的 CLI）。收起/展开继续用 `<details>`，只改样式。搜索框是带样式的原生 `<input>`。组件在 `file://` 下不能有网络请求、`eval` 或外部字体。
- **D8 视觉**：颜色、圆角、间距写成 CSS 变量令牌（参考手册的青绿主色、浅灰底、白色卡片、P0/P1/P2 红/橙/灰三档）；筛选器是一行工具栏，窄屏下换行但每个筛选器的标签与控件对齐；统计数字从数据里已有的计数字段渲染成键值网格，不再拼成长句（数据里只有拼好的句子的地方保持原样，不解析）。字体仍是内联的 Inter 加系统中文字体，不引入网络字体。

## Oracle

- **O1 组件测试**：侧栏只有一个滚动容器且含功能列表；源码位置默认收起、展开后每项有路径、主张与引用块，同一文件合并；发现表的位置列用引用块；路径里有断点。先红后绿。
- **O2 截图核对**：用一次真实运行的页面数据重新生成页面，在 1440×900、1024×768、390×844 三种窗口下截图首页、一个功能页、发现页、数据页、覆盖页；核对侧栏能滚到最后一个功能，发现一列不再竖排，源码位置收起。截图只放在本机，不进仓库。
- **O3**：页面包的测试与模板测试、受影响的手册测试、`check-refs`、`openspec validate --all --strict` 在本地跑；全量交给 PR 的 CI。
- **O4 控件**：组件测试——下拉选择用键盘打开、移动、确认后筛选结果随之变化，三个筛选器组合后计数正确；模板检查仍通过（一个文件、ASCII、许可说明列出新增的包）。用无头 Chrome 以 `file://` 打开真实运行生成的页面，控制台无错误、除 `data:` 外无网络请求；在 1440、1024、390 宽下截图发现页（下拉展开与收起各一张）、字典页、首页。
